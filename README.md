# InkubatorRuang

Inkubator Ruang untuk menjaga suhu fermentasi antara 20-35C.
Pemanas menggunakan Resistor dan pendingin menggunkan Peltier.
Kontrol Suhu Menggunakan PID dan interupt. Sensor Suhu dengan DS18B20.
